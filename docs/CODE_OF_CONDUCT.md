# Code of Conduct

## Our commitment

We want participation in KMAruda Phonebook to be a harassment-free experience
for everyone, regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, religion or
sexual identity and orientation.

## Expected behavior

- Be respectful and specific when discussing code or design.
- Assume good faith; critique the change, not the person.
- Accept feedback gracefully and give actionable feedback in return.
- Respect privacy: do not publish another person's logs, paths, keys, employee
  data or personal data without permission.
- Follow the project's security process for vulnerabilities.

## Unacceptable behavior

- Harassment, insults, threats or discriminatory language.
- Sexualized language or imagery, or unwanted attention.
- Publishing private information without explicit permission.
- Deliberate disruption of issues, pull requests or discussions.
- Retaliation against anyone who reports a concern.

## Scope

This code applies in repository spaces: issues, pull requests, discussions,
reviews, commit messages and project chat channels. It also applies when an
individual represents the project in public spaces.

## Enforcement

Maintainers may remove comments, close threads, reject contributions or ban
participants for behavior that violates this code. Enforcement decisions are
made in private and communicated to the people involved.

To report a concern, contact the maintainer through the GitHub profile linked in
the repository. For security issues, use [SECURITY.md](SECURITY.md).
